# Fonts

- **Satoshi** (Regular, Medium, Bold) by Indian Type Foundry, from Fontshare.
  Free for personal and commercial use under the ITF Free Font License.
- **Headings** use Pixelify Sans from Google Fonts (SIL Open Font License) as a free stand-in
  for PP Mondwest, the pixel serif on HackerRank Campus Crew. PP Mondwest is a paid font
  from Pangram Pangram. To use it, buy a web licence, put `PPMondwest-Regular.woff2` in this
  folder, and switch the `display` font in `src/app/layout.tsx` to `localFont`.
