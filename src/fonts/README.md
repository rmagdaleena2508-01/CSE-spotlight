# Fonts

- **Satoshi** (Regular, Medium, Bold) by Indian Type Foundry, from Fontshare.
  Free for personal and commercial use under the ITF Free Font License.
- **Headings** use Pixelify Sans from Google Fonts (SIL Open Font License) as a free stand-in
  for PP Mondwest, the pixel serif on HackerRank Campus Crew. PP Mondwest is a paid font
  from Pangram Pangram. To use it, buy a web licence, put `PPMondwest-Regular.woff2` in this
  folder, and switch the `display` font in `src/app/layout.tsx` to `localFont`.

## Hero headline

- **Headline:** meant to use **RL Madena** by Rough Lines Type (free for personal and commercial use,
  https://roughlinestype.gumroad.com/l/cmadnk). Until the file is added, **Young Serif** (Google Fonts) stands in.
- **The word "CSE":** meant to use **Buche** by Factory738 (free for personal and non-profit use;
  commercial use needs a licence from https://www.myfonts.com/collections/buche-font-factory738).
  Until the file is added, **Fraunces** (Google Fonts) stands in.
- To switch: put `RLMadena-Regular.woff2` and `Buche-SemiBold.woff2` (or their `.otf`/`.ttf`) in this
  folder, then change `headline` and `cse` in `src/app/layout.tsx` from Google fonts to `localFont`.
